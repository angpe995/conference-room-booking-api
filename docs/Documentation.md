# Коротка документація проєкту

## 1. Опис бізнес-завдань (Business Overview)

### Призначення системи
Система призначена для автоматизації процесів оренди та бронювання конференц-залів для бізнесу. Вона дає змогу компаніям керувати доступними приміщеннями, контролювати бронювання, визначати вартість послуг і отримувати аналітику щодо використання залів.

### Ключові бізнес-функції
- Управління конференц-залами: створення, редагування, видалення, перевірка доступності.
- Управління додатковими послугами: проєктор, Wi-Fi, звук, інші сервіси, які можуть бути прив’язані до кімнати.
- Пошук вільних приміщень за параметрами: місткість, час, тип події та доступність.
- Бронювання приміщень з перевіркою конфліктів у часі.
- Автоматичний розрахунок вартості оренди на основі часу та сервісів.
- Формування звітів для керівництва та менеджерів.

### Бізнес-логіка ціноутворення
Для підтримки ефективного управління витратами та прибутком система використовує сценарний підхід до ціноутворення залежно від часу бронювання:

- Стандартні години: 09:00–18:00 — базова ціна.
- Вечірні години: 18:00–23:00 — знижка 20%.
- Ранкові години: 06:00–09:00 — знижка 10%.
- Пікові години: 12:00–14:00 — націнка 15%.

Такий підхід дозволяє враховувати різну популярність часових інтервалів і підтримувати більш гнучку тарифну політику для клієнтів.

### Розрахунок вартості бронювання
Вартість бронювання формується з базової ціни оренди залу, тривалості бронювання та додаткових послуг, обраних клієнтом. У системі бронювання доступні лише цілі години, тобто початок і кінець бронювання мають збігатися з початком години.

Наприклад:
- валідно: 10:00–12:00
- валідно: 09:00–10:00
- невалідно: 11:20–12:20

Таке правило забезпечує узгодженість між розрахунком вартості, перевіркою доступності залів і формуванням звітів. Якщо бронювання охоплює кілька часових зон, ціна розраховується окремо для кожного сегмента й потім підсумовується.

### Звіти та аналітика
Система формує аналітичні звіти для бізнес-користувачів:
- щогодинні звіти про кількість бронювань;
- звіти про дохід по кожному залу;
- оцінку завантаженості кімнат у різні періоди часу.

Це дає можливість управляти ефективністю приміщень, оптимізувати завантаження та приймати рішення щодо тарифів і розподілу ресурсів.

## 2. Технічні рішення (Technical Overview)

### Архітектура
Проєкт побудовано за сервісною (service-based) архітектурою з чітким поділом відповідальностей між шарами:

- Controllers — приймають HTTP-запити та формують відповіді.
- Services — містять бізнес-логіку, валідацію та обчислення.
- DTOs — використовуються для передачі даних між рівнями і відокремлення внутрішньої моделі від API-інтерфейсу.
- Models — описують сутності домену та структуру даних у базі.

Такий підхід покращує підтримуваність, спрощує тестування та дозволяє масштабувати систему без сильного зв’язування компонентів.

### Обробка помилок
У проєкті реалізована централізована обробка винятків через GlobalExceptionHandler. Це дозволяє:
- стандартизовано перетворювати помилки у відповіді HTTP;
- обробляти конфлікти, відсутність даних та інші типові сценарії в одному місці;
- використовувати стандарт Problem Details для зручного і прогнозованого API-взаємодії.

### Робота з даними
Для зберігання даних використовується Entity Framework Core з PostgreSQL. Це забезпечує:
- зручну роботу з доменною моделлю через ORM;
- контроль версій схеми за допомогою міграцій;
- стабільну інтеграцію з бізнес-логікою проєкту.

### Тестування
Проєкт має модульні тести на базі xUnit, які покривають основну бізнес-логіку:
- створення та валідація бронювань;
- перевірка конфліктів бронювань;
- розрахунок вартості та цінових правил;
- перевірка доступності залів;
- генерація звітів.

Таке покриття дозволяє стабільно підтримувати роботу API і мінімізувати ризик регресій при зміні логіки.

## Підсумок
Проєкт реалізує повноцінну систему для управління конференц-залами, яка поєднує бізнес-логіку, аналіз використання ресурсів і чисту архітектуру програмного рішення. Він відповідає вимогам автоматизації бронювання, контролю доступності, розрахунку вартості та формування звітів для бізнес-користувачів.
